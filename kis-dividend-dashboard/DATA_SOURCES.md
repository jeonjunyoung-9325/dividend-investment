`한국투자증권 공식 API 확인 결과`를 따릅니다.

### 공식 API에서 확인하지 못한 데이터

- 일반 개인계좌 국내·해외 실제 배당 입금을 세전·세금·실수령액으로 완전하게 제공하는 전용 API
- 일반 주식 계좌의 범용 입출금 원장 API
- 해외 권리 이벤트만으로 개인 계좌의 수령 자격을 확정하는 방법
- 각 오류의 정확한 HTTP 상태 코드와 `Retry-After` 헤더

위 항목은 **미확인**으로 취급하며 API 이름, 필드 또는 값을 추측하지 않습니다. 공식 API가
불완전한 실제 배당 내역은 아래 CSV·XLSX 또는 직접 입력으로 보완합니다.

## 사용자 업로드 CSV·XLSX

한국투자증권에서 사용자가 직접 내려받은 거래·배당 내역 파일은 실제 지급 내역의 우선 폴백입니다.
CSV는 UTF-8, UTF-8-SIG, CP949를 지원하고 XLSX는 메모리에서만 파싱합니다. 원본 파일은 서버에
영구 저장하지 않습니다.

사용자가 미리보기와 컬럼 매핑을 확인한 뒤 저장하며, 파일 hash와 행별 `import_hash`로 동일
파일·동일 행의 중복 저장을 막습니다. 저장된 행은 `source`를 공식 API와 구분합니다. 파일의
열 이름만으로 세전·세금·실수령액 의미가 명확하지 않으면 자동 추정하지 않고 오류 또는 수동
매핑 대상으로 표시합니다.

## 사용자 직접 입력

공식 API와 업로드 파일로 확인할 수 없는 실제 배당 내역, 종목별 예상 세율, 예측 방식 및 사용자
지정 연간 주당 배당금을 입력할 수 있습니다. 직접 입력값은 공식 발표값으로 승격하지 않으며
출처를 `manual`로 표시합니다.

## 외부 배당 데이터 제공자

기본 구현은 확인되지 않은 외부 배당 제공자를 자동 호출하지 않습니다. 추후 검증 가능한 제공자를
추가하면 제공자명, 조회 시각, 기준일, 실시간 여부, 마지막 정상값 여부를 화면에 표시해야 합니다.
외부 데이터는 실제 입금액의 증거로 사용하지 않습니다.

## 외부 환율 데이터 제공자

환율은 한국투자 공식 API에서 확인된 원화평가 기준환율을 우선 사용합니다. 사용할 수 없으면
검증 가능한 무료 환율 API, 사용자 설정값, 마지막 정상 저장값, 기본 설정값 순서로 대체합니다.
현재 외부 제공자가 설정되지 않았으면 `외부 제공자 없음`으로 표시하며 임의 출처를 만들지 않습니다.

## 마지막 정상 저장 데이터

API 또는 외부 제공자 호출이 실패해도 기존 정상 데이터를 삭제하지 않습니다. 저장된 값에는 원래
출처와 최초 조회 시각을 유지하고 `마지막 저장값 사용` 상태를 추가합니다. 마지막 정상 환율을
사용하면 실시간 환율이 아니며, 화면에 실패와 대체 적용 사실을 표시합니다.

## 계산된 확정 예정 배당금

공식 발표 주당 배당금과 **기준일 당시 확인된 수량**이 모두 있을 때만 확정 예정 금액을 계산합니다.
현재 보유수량은 기준일 수량의 대체값이 아닙니다. 기준일 수량이 없으면 금액을 확정하지 않고
`수령 자격 확인 필요`로 표시합니다.

## 계산된 향후 12개월 예상 배당금

과거 실제 또는 발표 배당 이력, 현재 보유수량, 사용자가 선택한 예측 방식과 가정 세율로 계산한
추정치입니다. 공식 지급 약속이나 세무 계산이 아닙니다. 적용 방식, 데이터 기간, 표본 수, 추정
지급주기, 마지막 데이터 날짜, 충분성, 신뢰도와 원본 출처를 함께 표시합니다.

모든 예상값에는 `추정치이며 실제 지급액과 다를 수 있습니다.`를 표시합니다.

## 출처·조회 시각·기준일·실시간 여부 표시 규칙

| 표시 항목 | 규칙 |
| --- | --- |
| 데이터 출처 | KIS 공식 API, 사용자 업로드, 직접 입력, 외부 제공자, 계산값을 구분 |
| 조회 시각 | UTC로 저장하고 Asia/Seoul로 변환해 표시 |
| 기준일 | 잔고 스냅샷일, 배당 기준일, 환율 기준일 등 데이터 의미에 맞는 날짜 |
| 실시간 여부 | 공식 문서상 실시간이 확인된 경우만 실시간. 그 외는 지연·기준환율·비실시간으로 표시 |
| 마지막 정상값 | 새 조회 실패 후 저장값을 사용한 경우 명시 |
| 실제/확정/예상 | 색상뿐 아니라 텍스트 라벨로 구분 |

## 데이터 없음과 계산 불가 처리

출처가 없거나 필수 필드가 부족하면 0 또는 가짜 값으로 채우지 않습니다. `데이터 없음`,
`계산 불가`, `수령 자격 확인 필요`, `예측 불가` 중 의미에 맞는 상태를 표시합니다. 일부 거래소만
실패한 경우 성공한 거래소 데이터는 유지하고 실패 거래소와 조회 시각을 별도 경고로 표시합니다.
